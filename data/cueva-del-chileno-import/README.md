# Cueva del Chileno import

Staging package for the Cueva del Chileno archaeological site entry.

Primary source:

- Melanie J. Miller, Juan Albarracin-Jordan, Christine Moore, and Jose M. Capriles, "Chemical evidence for the use of multiple psychotropic plants in a 1,000-year-old ritual bundle from South America," *Proceedings of the National Academy of Sciences* 116, no. 23 (2019): 11207-11212. https://doi.org/10.1073/pnas.1902174116.

Images are from UC Berkeley / Penn State / PNAS release materials and are credited individually in `document_figures.json`.
